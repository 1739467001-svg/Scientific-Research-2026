## 0. 归属判定规则（两个台账共用）

| 判定 | 条件 | 一句话 |
|---|---|---|
| **→ A 轨** | 关键词的**对象**是生物医学实体（细胞、蛋白、mRNA、靶点、疾病、患者、实验平台），或来自导师分享与课题组方向 | **"它研究的是什么东西"是生物的** |
| **→ B 轨** | 关键词的**对象**是数学/统计构造（估计量、检验、分布、指标、实验设计、推断方法），脱离具体生物背景依然成立 | **"它研究的是什么东西"是数学的** |
| **→ 交叉** | 一个统计构造被用来**裁决**一个生物问题；或一个生物问题的瓶颈**本质上是统计问题** | **两边都要记，这是差异化所在** |

> ⚠️ **交叉项同时写入两个台账**，并互相标注。**这一类是本台账最有价值的部分**——见 §3。

## 2. 本轨当前的主线判断

> 摘自知识库累积洞察，供汇报直接引用：

1. **课题组主线 = 单细胞/多组学 AI + 生命科学大模型**，导师转发多为该主线的竞品扫描或路线图校准（洞察 1）
2. **真正的资产是数据，不是模型**——四条情报独立印证（洞察 11）
3. **验证器/评估体系是这个领域的真正瓶颈**（洞察 9、28）
4. **可重放性是干实验与湿实验 RSI 的分水岭**；课题组主线在"AI 自主科研"叙事里的角色，是**造出那个可重放的环境**（洞察 29）⭐ 最适合写进开题

## 3. ⭐ 交叉关键词（同时记入 B 轨）

> **这一节是两个身份的真正交汇点。** 每一条都是"生物问题的瓶颈其实是统计问题"。

| 交叉关键词 | A 轨的问法 | B 轨的问法 | 关联 |
|---|---|---|---|
| **排序 vs 定量** | 模型能不能预测扰动后的表达量？ | **Spearman 高而 MAE 输朴素基线，说明模型学到的是序而非尺度——这是校准问题** | 洞察 15（四次印证） |
| **验证器设计** | 怎么判断一个设计出来的分子是好的？ | **选什么估计量、用什么对照、谁来裁决** | 洞察 9、28 |
| **实验室在环（Lab-in-the-Loop）** | 怎么让计算与湿实验形成闭环？ | **序贯实验设计 / 主动学习：下一批测什么最有信息量** | 洞察 16、25 |
| **离线策略评估** | Dream-RSI 怎么不跑实验就评估新策略？ | **off-policy evaluation 本身就是统计学课题** | 情报 009 |
| **对照缺失 → 假阳性** | 谷歌适配体第二轮特异性为何崩塌？ | **缺对照筛选；G-四链体造成非特异结合被当成命中** | CHK-001 |
| **小样本推断** | 3 例 ITP、9 例 EVM16 能说明什么？ | **n 很小时，点估计几乎不可解释，必须给区间** | 情报 006、CHK-001 |
| **命中率的区间估计** | 42.1% 比 26.0% 真的更好吗？ | **比例差异需要置信区间与检验，原文只给了点估计** | CHK-001（见 B 轨 §3 的实算） |
| **置信度 ≠ 真值** | i_pTM/pLDDT 能当亲和力用吗？ | **模型置信度的校准（calibration）问题** | 情报 008 |
| **最优传输（OT）** | 怎么分离批次噪声与扰动信号？ | **概率测度之间的距离，统计/概率工具** | 情报 003 |
| **知识联邦 / 联邦学习** | 多中心医疗数据不共享怎么建模？ | **分布式统计推断、隐私保护统计** | 导师档案 §5 |
| **影响因子的偏态** | npj 哪本 IF 高？ | **IF 是均值，被少数高被引论文拉偏；应同时看 5 年 IF** | 情报 007 |
| **AI 修订验证器** | BigHat 的热稳定/聚集指标是否误导？ | **测量效度：指标是否测到了想测的性质；新指标需独立实验确认** | 情报 010、洞察 33 |
| **召回率 vs 精确率** | 文书审核智能体能否替代人工复核？ | **11/11 召回的 Wilson 下限约 74%；误报数未报告则精确率不可估** | 情报 010 |
| **临床成功概率的校准** | AI 能否评估临床方案成败？ | **概率预测需校准曲线 / Brier 分数 / 历史回测** | 情报 010 |
