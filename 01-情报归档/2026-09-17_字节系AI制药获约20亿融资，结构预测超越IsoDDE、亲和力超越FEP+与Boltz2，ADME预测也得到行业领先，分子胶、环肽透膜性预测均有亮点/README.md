## 0.5 ⭐ 白话导读：这篇文章到底在说什么

> 本节为**非专业读者**准备。原文术语密度极高，先把骨架讲清楚，再看后面的细节。

### 一、做一款新药，简化成四个连续的判断

```
①  药会贴在蛋白的哪个位置？           →  结构预测      →  AnewFold
        ↓  贴错位置，后面全白做
②  贴得牢不牢？几十个候选先合成哪个？   →  亲和力预测    →  AnewAffinity
        ↓  合成一个分子很贵，排序错了就是烧钱
③  除了贴得牢，它能进细胞吗？会中毒吗？ →  性质预测      →  AnewMind
        ↓  大量药不是"不管用"，是"性质不行"
④  这轮实验做完了，下一轮改哪里？       →  闭环设计      →  AnewDesign
        ↺  实验结果喂回算法，再出下一批候选
```

**「DDE」= Drug Design Engine（药物设计引擎）**，就是把这四步打包成一个系统。
Anew Labs 做的 AnewDDE，对标的是 Alphabet 旗下 Isomorphic Labs（DeepMind 分拆）的 **IsoDDE**。

### 二、这篇文章的结构

文章不是通稿，而是**逐模块核对技术报告的批判性解读**。每讲完一个模块的亮眼数字，作者都紧跟一句"**但是**"（全文共八处，见 §4）。

**标题极其"标题党"（超越、领先、亮点），正文却处处降温。这个反差本身就是本篇最值得注意的特征。**

### 三、核心术语速查

| 术语 | 白话解释 |
|---|---|
| **结构预测** | 预测蛋白质长什么形状、药物分子会贴在哪个位置。贴错 = 后面全白做 |
| **亲和力（affinity）** | 药和靶点结合得多牢。用 **K_D** 表示，**数字越小越牢**；nM（纳摩尔）级是好药门槛 |
| **ΔG / ΔΔG** | 结合自由能 / 两个分子结合自由能之差。物理上衡量"贴得多牢"的量 |
| **FEP+** | 基于物理模拟的传统算法，**算亲和力最准但极慢极贵**。是 AI 要打败的"金标准" |
| **Boltz-2** | MIT + Recursion 2025 年**开源**的亲和力预测模型，号称接近 FEP 精度而快 1000 倍 |
| **IsoDDE** | Alphabet 旗下 Isomorphic Labs 的同类引擎，**当前公认最强对手，但完全不公开** |
| **AF3** | AlphaFold 3 |
| **ADME / ADMET** | 吸收、分布、代谢、排泄（+毒性）。药进入人体后的命运。**很多药不是不管用，是 ADME 不行** |
| **CYP2C9/2D6/3A4** | 肝脏里代谢药物的三种酶。抑制它们会引起药物相互作用 |
| **分子胶** | 一类特殊的药，自己不起效，而是把两个蛋白"粘"在一起让细胞降解其中一个。**预测特别难，因为要同时算对三样东西** |
| **环肽透膜性（PAMPA）** | 环状多肽药能不能穿过细胞膜——**肽类药最大的障碍** |
| **纳米抗体 / VHH** | 一种特别小的抗体片段（源自羊驼），易生产、能钻进小口袋 |
| **SPR** | 表面等离子共振，测结合强度的标准实验方法 |
| **Lab-in-the-Loop** | 算法出候选 → 实验验证 → 结果喂回算法 → 下一轮更好 |
| **DockQ** | 衡量预测的复合物结构与真实结构有多接近的评分，>0.8 为高质量 |
| **Elo-AUROC / Elo-Spearman** | 多模型两两比较后折算的排名分，用于横向比较一堆模型 |

## 3. 四个模块逐一拆解

### 3.1 AnewFold（结构预测）：贴在哪里？

**任务**：如果抗体落在错误表位、或小分子被放入错误口袋，**再精细的优化也可能离目标越远**。

| FoldBench 任务 | **AnewFold** | IsoDDE | Protenix-v2 | AF3 |
|---|---|---|---|---|
| 抗体–抗原 | **76.2%** | 75.6% | 65.0% | 48.8% |
| 蛋白–配体 | **77.4%** | 76.0% | 64.0% | 64.9% |

**领先幅度：+0.6 和 +1.4 个百分点。**

> ⚠️ **作者的降温**：这只说明 AnewFold 进入了领先梯队；**如此小的点估计差距，不足以支撑"统计显著的全面超越"。**（原文此句截图辨识略有不确定，但从上下文与作者一贯口径判断为此意，详见 `原文存档.md` 标注）

#### ★ 真正的亮点在分子胶三元复合物

| 模型 | 联合成功率（131 个共同案例） |
|---|---|
| **AnewFold** | **71.8%** |
| Protenix-v1 | 45.0% |
| Protenix-v2 | 29.8% |
| Boltz-1 | 22.1% |

**相对最强对照高出 26.8 个百分点——这才是真正拉开差距的地方。**

> 💡 **为什么分子胶难**：需要**同时**算对蛋白–蛋白界面、配体位置、局部相互作用**三件事**，考验多组分体系的结合几何关系。单项都对、组合不对，仍然算失败。
>
> ⚠️ **作者的降温**：**该组分子胶评测未纳入 IsoDDE，因此不能延伸为"对 IsoDDE 的胜出"。** —— 这是全文最关键的一处限定。**标题写"超越 IsoDDE"，而最能拉开差距的那一项恰恰没有 IsoDDE 参赛。**

**其他亮点（来自图注）**：在 **BNP 基准**的**最低相似度区间**（与训练集最不像的那些），AnewFold 仍保持第一，而基线模型在这里**下滑最剧烈**——这是**泛化能力**的证据，比平均分更有说服力。代表性的分布外案例包括 **KRAS G12D Switch-II 隐藏口袋**、**TRIM58 PRY-SPRY 识别口袋**、**mavacamten β-心肌肌球蛋白变构口袋**。

> ⚠️ **作者的降温**：上述百分比衡量的是**结构预测成功率，不能当作湿实验命中率**。

### 3.2 AnewAffinity（亲和力）：★ 排序赢、定量输

**任务**：几十种修改方案，**优先合成哪几个**？

**8 个靶点、199 个配体的回顾性测试，与 Boltz-2 同批比较**：

| 指标 | **AnewAffinity** | **Boltz-2** | 谁赢 |
|---|---|---|---|
| **ΔΔG RMSE**（绝对误差，越低越好） | 1.057 kcal/mol | **1.016 kcal/mol** | ❌ **Boltz-2 赢** |
| **ΔG 加权 Pearson R²**（越高越好） | **0.553** | 0.486 | ✅ AnewAffinity |
| **ΔG 加权 Spearman**（越高越好） | **0.724** | 0.620 | ✅ AnewAffinity |

> 🔑🔑 **这是本篇对本知识库最重要的一条数据。**
> **AnewAffinity 在两个「排序类」指标上明显赢，却在唯一的「绝对误差」指标上输。**
> 作者自己的总结："**AnewAffinity 在亲和力趋势和排序上更好，绝对误差则 Boltz-2 略低。**"
> 并指出这对实验资源有限的团队仍有实际意义："**即使一个模型不能准确报出每个分子的亲和力，只要它能更有效地识别优先级，也可能帮助团队改善候选选择。**"

**其他数据**：端到端 **1.5 秒**完成一次配体对变换评估。BACE 案例中预测 ΔΔG **+1.12 kcal/mol**，实验 **+1.33 kcal/mol**。

> ⚠️ **作者的降温**：速度–性能对比**混合了不同数据集、硬件与计时口径**，不能据此宣称相对 FEP 的严格万倍加速（§2.4 已佐证）。

### 3.3 AnewMind（性质与推理）：医药领域后训练的千亿参数 LLM

**定位**：经过医药领域**全参数后训练**的千亿参数量级大语言模型。特点是在**部分专门任务上超过或接近强通用模型**。

| 任务 | AnewMind 成绩 | 名次 / 对照 |
|---|---|---|
| **环肽 PAMPA 透膜性排序** | **Elo-AUROC 0.737** | ✅ **17 个模型中第一**（最强对照 0.693，其后 0.678 / 0.668） |
| **CYP2C9 / 2D6 / 3A4 抑制** | 0.851 / 0.842 / 0.834 | ✅ **本次比较中最高点估计** |
| 抗体可开发性 | 平均 Elo-Spearman **0.247** | 🟡 第二，紧接第一名的 0.254 |
| 整体 ADMET 分类与连续性质排序 | — | 🟡 **第五** |
| **PharmBench** 整体 | **54.65%** | 🟡 第三 |
| PharmBench 分子设计与合成子项 | **60.83%** | ✅ 第一（次名 60.64%、60.40%） |

> 💡 **一个容易被标题掩盖的实情**：标题说"ADME 预测也得到行业领先"，但**整体 ADMET 排序其实只排第五**。真正第一的是**环肽透膜性**和**三个 CYP 抑制任务**——**是"部分任务领先"，不是"ADME 整体领先"。**

**PharmBench 的设计值得单独记一笔**：50 个研发情景、200 个问题，**逐步揭示实验信息，测试模型能否整合证据并调整判断**。
> 💡 这是一个**动态的、序贯的**评测设计，比静态问答更接近真实研发决策。**这个基准设计思路本身，对课题组做评测有借鉴价值。**

> ⚠️ **作者的降温（两处）**：
> ① 抗体可开发性"**绝对相关水平仍然有限**，不能理解成抗体性质已经可以可靠地替换大量判断"；
> ② "**PAMPA 通透性不能直接从直观上得出药性，内部基准成绩也不能直接推算成真实的项目成功率。**"
> ③ 图注明确：**不同分子类型使用不同评价指标，分数不可跨面板直接比较。**

### 3.4 ★ AnewDesign（闭环设计）：全文唯一的湿实验证据

**这是唯一一个把计算推回实验、并给出真实数字的案例**——针对一个**未公开的内部蛋白靶点**做纳米抗体设计。

```
表位分析
   ↓
初选 3,092 个序列
   ↓
筛选得到 287 个簇
   ↓
选出 50 个序列  →  【首轮湿实验】
   ↓
7 个结合命中，SPR 测得 K_D = 46–390 nM
   ↓  实验反馈回流，亲和力成熟（保留已验证区域，优化 CDR 及邻近框架残基）
再测 100 个克隆  →  【第二轮湿实验】
   ↓
16 个候选，K_D = 1.8–8.1 nM     ← 亲和力提升约 50–100 倍
```

**两轮合计 150 个克隆 → 16 个达到纳摩尔亲和力 = 10.7%**

> 💡 **这个案例最有价值的地方**（作者原话）：**结果实际参与了下一轮候选设计与选择。已验证区域被保留，选定 CDR 及邻近框架残基继续优化，计算与实验有可追溯的迭代过程。**
> 这不是"算法跑完交给实验"，而是**真正的双向闭环**。

> ⚠️ **作者的降温（最重要的一处）**：
> **"这仍然是单个内部靶点的概念验证，现阶段证明的是结合亲和力，功能和可开发性还要继续评价。它也不能用来证明所有模块已经在同一个项目中完成端到端验证。"**
> 换言之：**AnewFold → AnewAffinity → AnewMind → AnewDesign 四个模块串起来的端到端故事，目前没有被任何一个完整项目验证过。**

### 6.1 ⭐⭐⭐ 「排序 vs 定量」：第三条独立印证，此判断已彻底坐实

> **这已经不是巧合，而是当前 AI for Science 模型的结构性特征。**
>
> **可直接用于课题设计的推论**：
> ① **选题优先选排序类任务**（候选筛选、靶点排序、新抗原挑选），避开需要绝对定量的任务；
> ② **评测必须同时报告两类指标**，并明确说明在哪类上赢；
> ③ 若要在定量上取得突破，**那本身就是一个值得做的课题**，因为三个子领域都卡在这里。
